# Security Policy

wwwallet is a non-custodial wallet, so security reports matter. Please report vulnerabilities **privately** — do not open a public issue or pull request.

Use GitHub's private reporting: **Security → Report a vulnerability** on this repository
(<https://github.com/omnidium/wwwallet/security/advisories/new>).

Please include what you found, steps to reproduce, and the affected version or commit. Reports are handled on a best-effort basis; there is no bug bounty.

The source is available for review under the [PolyForm Strict License 1.0.0](LICENSE). Security research consistent with that license (reading and auditing the code, and testing an unmodified copy for noncommercial purposes) is welcome; please don't test against other people's wallets or against the production backend beyond normal use, and don't disrupt the service.
